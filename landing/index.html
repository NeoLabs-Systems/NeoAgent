A chat window forgets you the moment it answers. NeoAgent is built the other way around: it's a service with memory, hands, and a schedule — and the chat is just one door into it.

01

It has hands

A real browser, a terminal, your Android phone, your desktop. It taps, types, and scrolls on actual interfaces — no mocked demos.

02

It has memory

Durable facts stored as structured local data, separate from chat history. Newer information replaces older. You can read, edit, or erase all of it.

03

It has a schedule

Routines and event triggers keep running while you sleep. Every action lands in a log you can inspect — or stop.

Chat

Say it once, in your own words.

Type or talk — from the dashboard, Telegram, WhatsApp, or email. NeoAgent streams its thinking and its tool calls live, so you can watch it work or walk away. Both are fine.

Memory

It remembers so you can stop repeating yourself.

Facts, people, preferences, and how they connect — stored as structured data on your machine, not as vibes in a chat log. Hover the graph: everything is inspectable, editable, deletable.

Automation

The 10 p.m. version of you has opinions too.

Describe a routine once and it runs on schedule — or fires on events. No node editors, no flowcharts. Plain language in, quiet competence out, and a full run log either way.

remote devices
Real hands, real screens

It taps the same buttons you would.

NeoAgent operates a live browser, an Android phone, or a desktop the way a person does — finding the field, typing into it, waiting for the page. When it gets stuck, you take over the same screen with one click. No API for that airline's clunky portal? Doesn't matter.

  • Live browser, phone & desktop control
  • Watch every session as it happens
  • Take over instantly, hand back just as fast

One agent, whichever door you knock on —

Telegram WhatsApp Email Voice calls Live browser Android Desktop Calendar MCP tools Home Assistant

— and it keeps one shared context across all of them. Tell it something on Telegram, it knows in the dashboard.

Yours, actually

It runs where you put it.

A Mac mini in the closet, an old ThinkPad, a VPS, or a box you never touch. Wherever it runs, your memory, credentials, and logs stay somewhere you can ls them. The desktop installer sets everything up without a terminal; the CLI is there when you'd rather have one.

  • Structured memory stored as local data, erasable any time
  • Every tool call logged and inspectable
