# Display font

`neoagent_latin_16.c` is a subset of IBM Plex Sans Regular, generated with
`lv_font_conv` 1.5.3 at 16 px and 2 bits per pixel, without kerning or compression. It includes
Basic Latin, Latin-1 Supplement, Latin Extended-A/B, general punctuation, the
euro sign and the trademark sign. Characters absent from this subset cannot be
rendered by this font.

Source: [IBM Plex Sans Regular, revision 48e8676](https://github.com/IBM/plex/blob/48e8676114c04f29033b4b53da4ec579f8846297/packages/plex-sans/fonts/complete/ttf/IBMPlexSans-Regular.ttf).
