# Hardware

*An optional source-level firmware target for a small wearable.*

NeoAgent includes a dedicated ESP-IDF wearable firmware target under
`firmware/neoagent_wearable_esp32s3_amoled` for the Waveshare ESP32-S3 Touch
AMOLED 1.8 board.
